# Code of Conduct

Be kind, assume good intent, and keep discussions about the work. Harassment, insults and
personal attacks aren't welcome in issues, discussions or pull requests, and will be removed.
Repeated or serious cases lead to a ban from the project.

If something here makes you uncomfortable, report it privately to the maintainer through
[GitHub's private reporting](https://github.com/fanckush/SoundOwl/security/advisories/new) or by
contacting @fanckush on GitHub.

This project follows the spirit of the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
